## Unresolved failures

- **trpc**: Nuxt schema imports undeclared `scule`. The dependency exists in the project hidden hoist, but a package realpath in the global virtual store cannot reach that project tree. This is distinct from the previously documented `fnpm run` limitation and remains FAIL.
- **create-t3-turbo**: the source pnpm lock binds an Expo peer declared as `^6.1.2` to `6.1.1`; fnpm adds `@expo/metro-runtime@6.1.2`. Verification passes and unique package sets are stable, but physical instances fall from 1428 to 1418 on warm/frozen installs.
- **t3-env**: the source bun lock has older workspace versions and needs partial resolution. Fifteen older/optional peer packages disappear, including ioredis and React 18 copies, along with the loose-envify bin. Verification passes, but installed-package parity fails.
