# Fuck NPM / fnpm documentation site

An Astro site with Bun's page shell, typography, navigation and card styles
adapted for fnpm. The welcome page, package-manager navigation and selected
explanations adapt Bun docs. Astro renders MDX, Expressive Code formats terminal
examples, and Pagefind indexes the static output. The site has its own manifest
and lockfile; it does not change the repository's npm workspaces.

Requires Node 22.23.4+; Node 24.22.1 was used for the verified builds.

```sh
cd website
npm ci
npm run dev
```

Build static files and preview them with:

```sh
npm run build
npm run preview
```

Production output is `website/dist/`, including the Pagefind search index. The
site is deployed to <https://fuck-npm.vercel.app/> by Vercel's GitHub integration
(project root `website/`; every push to `main` deploys production, pull requests get
previews) with `vercel.json` (the build sets `DOCS_SITE` for canonical URLs, Open Graph tags and
the sitemap). Every page is prerendered to static HTML. For a GitHub Pages project
path, build with:

```sh
DOCS_SITE=https://snowingfox.github.io DOCS_BASE=/fuck-npm/ npm run build
```

The [home page](src/components/Home.astro),
[documentation welcome page](src/content/docs/docs.mdx),
[benchmark overview](src/content/docs/benchmarks/overview.md), and
[real-project details](src/content/docs/benchmarks/real-projects.md) display the
measured OpenNext Cloudflare, OpenCode, tRPC, Excalidraw and Jest results. The
last page includes pnpm/Yarn baselines, timing variation, package-set differences,
source revisions, exact checks and script-enabled OpenNext evidence. Measurements
come from the tracked reports under `bench/results/`; they are not regenerated by
the documentation build.

Navigation is defined in `docs.json`; pages live in `src/content/docs`.
`src/components/Page.astro` renders the shared shell; `Home.astro` renders the
landing page. Homepage chart values are parsed from the committed real-project
report into `src/data/benchmarks.json`; they retain measured tool versions, and
all project/scenario selectors share that dataset. Bun's published stylesheet
is retained in `src/styles/bun-site.css`; fnpm overrides live in `custom.css`.
Locally hosted Archivo/Martian Mono fonts retain their OFL notices. Update
release status from `../docs/RELEASING.md` and identify benchmark revisions when
changing content. `fnpm@0.0.2` remains a public npm candidate until registry
publication and fresh-registry checks complete.

Source attribution and the original Bun license are preserved in
[NOTICE.txt](public/licenses/NOTICE.txt) and
[bun-LICENSE.md](public/licenses/bun-LICENSE.md). The fnpm logos are original SVG
wordmarks; the site distributes no Bun mascot or proprietary Mintlify components.
