## What's Inside

- **Package manager:** dependency installation, workspaces, overrides, scripts, and lockfile migration.
- **Native hot paths:** Rust launchers handle installation without Node startup.
- **Shared package store:** clone or link package files to reduce duplicate disk use.
- **Lockfile toolkit:** inspect and verify `fnpm.lock`, migrate existing formats, and export for other tools.
- **Package runner:** `fnpx` and `fnpmx` run package executables.

## Measured in real repositories

The Linux snapshot records three-run medians of cold, warm, and no-op installs in five pinned repositories. fnpm had lower warm and no-op medians than Bun in all five; cold installs were lower in two of five. Read the [full results and limitations](../benchmarks/real-projects/), including package-set differences and project checks.
